Legend
Trigger / Release — the demo start (prompt to Devin) and the final released app
Devin phase — an automated step Devin executes end-to-end
Human checkpoint — a person must review and approve before the next phase
The amber diamond nodes are human-in-the-loop gates. Devin pauses at each gate until a human approves: the assessment (Tech Lead), the construct-mapping rules and the target architecture (Architect), the migration PR before merge (Reviewer), and the final release (Release Manager). Nothing advances past a gate without a human.
